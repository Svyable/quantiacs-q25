# quantiacs-q25 — Q25 Quantitative Research Lab

> **Causal crypto alpha, with a memory.** We preregister mechanisms, run exact public/default Quantiacs evaluation, attack them with matched controls, preserve failures, and let forward evidence overwrite attractive development stories.
>
> 🌐 **Live research surface:** https://svyable.github.io/quantiacs-q25/ · 📊 [Methodology health](docs/METHODOLOGY_HEALTH.md) · 🧭 [Strategy atlas](docs/STRATEGY_ATLAS.md) · 🧪 [Research matrix](docs/RESEARCH_MATRIX.md)

This repository is the research-and-validation stack for the **Quantiacs Q25 Crypto Top-10 Long** contest. The goal is not to manufacture one spectacular backtest. The goal is to discover the smallest set of **causal, distinct, cost-aware mechanisms** that can survive chronology, controls, drawdown, turnover, validation, cleaner, multipass and uniqueness checks.

**The repository is the source of truth.** GitHub Pages is the visual control surface. Measured claims originate in frozen experiment artifacts and generated health packets before they appear in narrative copy.

## The recursive research operating system

```text
map nearest incumbents
        ↓
form a mechanism hypothesis
        ↓
preregister parameters + controls + fold boundaries
        ↓
causal implementation + static audit
        ↓
prefix invariance + bounded replay
        ↓
exact research/dev measurement on the shared cost ladder
        ↓
matched ablation + destructive falsifier
        ↓
residual/originality diagnostics vs incumbents
        ↓
PROMOTE / RESERVE / KILL / FALSIFY
        ↓
frozen forward validation — no rescue tuning
        ↓
current Quantiacs cleaner + multipass + account-bound uniqueness
        ↓
live-entry candidate
```

### Dogfood telemetry: a vector, not a mega-score

The loop tracks separate feedback channels instead of optimizing one gameable “research quality” number:

- **falsification coverage** — did the campaign include central parents, ablations and destructive controls?
- **causal support** — did the claimed transform beat both matched controls?
- **economic survival** — did any base clear the fixed robust development floor?
- **promotion-ready intersection** — causal support ∩ economics, still before validation;
- **decision resolution** — did the campaign actually end in a useful decision?
- **evidence-depth debt** — how far has the narrative moved beyond the last full comparable matrix?
- **validation state** — can newer frozen forward evidence supersede older development guidance?
- **measurement queue** — is any preregistered campaign ahead of committed evidence?

**Aggregate score: forbidden. Optimization target: false.** The telemetry exists to improve the process, not become the next thing the agent overfits.

## Strategy map: what we are exploring now

The frontier has moved beyond “another momentum variant.” Current and recent objects include:

- **cross-sectional capital migration** — dollar-volume share movement as an ownership/attention reallocation signal;
- **local network detachment** — when assets lose strength to their nearest residual peers;
- **residual subspace rotation** — changes in the geometry of the common residual eigenspace;
- **cohort divergence** — whether trending leaders separate from their contemporaneous trend cohort;
- **sequence complexity** — permutation-entropy contraction as a transition from disorder toward structure;
- **relative-value convergence** — dispersion contraction with laggard ranking;
- **shock-recovery surfaces** — path/recovery objects that remain a distinct frontier after graph-statistic exhaustion;
- **execution-aware alpha density** — reward signal density that survives cost and turnover, not just raw score quality;
- **profile translations** — bounded Sharpe/volatility/trend/classifier combinations used as robustness controls, not novelty theater.

The novelty rule is strict: an independent alpha should differ from its nearest incumbent on at least **two** of information primitive, transform, timing/state and portfolio construction. Otherwise it is labeled a refinement or ablation.

## Reproduce the research path

No personal Quantiacs API key is required for local/public research. When `API_KEY` is absent or blank, the harness uses `API_KEY=default`. A participant credential is reserved for account-bound correlation/precheck, identity and submission operations.

```bash
conda install -c quantiacs-source qnt
# or
pip install "git+https://github.com/quantiacs/toolbox.git"
pip install -r requirements.txt

python -m pytest -q tests
python scripts/build_methodology_health.py --check
python scripts/build_research_dashboard.py --check
```

Re-run a frozen frontier exactly:

```bash
API_KEY=default python -m research.iteration \
  --manifest experiments/frontier_20260912k/manifest.json \
  --output results/frontier_20260912k --budget 18
```

Or run an individual strategy:

```bash
python scripts/run_strategy.py strategies/robust_weekly_waterfill.py
python scripts/run_strategy.py strategies/q25_sota_meta_ensemble.py
```

A missing personal credential is **not** permission to stop at code generation. If public/default data are reachable, the agent should measure the candidate and commit the evidence boundary honestly.

## Evidence lanes

| Label | Meaning |
|---|---|
| **Historical research** | frozen evidence from a dated prior campaign |
| **Observed local / public-default** | real Quantiacs-toolbox measurement with public/default access; not account-bound platform clearance |
| **Development-only** | selection evidence on declared research/dev folds; no forward claim |
| **Preregistered forward observed** | frozen candidate observed on a frozen validation fold; later evidence may invalidate the development narrative |
| **Conditional reserve** | interesting but limited by overlap, packaging, evidence depth or another declared boundary |
| **PENDING** | a specific layer has genuinely not run; missing evidence stays missing |

### Non-negotiables

- No invented Sharpe, return or drawdown figures.
- No future leakage, centered windows, hidden negative shifts or manual coin picks.
- Quantiacs-provided strategy fields only.
- Long-only; cash is a legitimate position.
- 25% per-asset cap is enforced before cleaner parity.
- Cost, turnover and liquidity are first-class objectives.
- Correlation / residual-alpha checks are promotion gates, not decorations.
- Spent validation folds stay spent.
- A strategy can be rejected even when its equity curve looks spectacular.
- **Dogfood the evaluator:** measure whenever the public/default research path is available.
